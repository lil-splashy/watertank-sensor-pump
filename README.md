# Water Tank Sensor





### Functional Requirements 
- Checks tank water levels daily
- Turns on water pump below designated threshold
- pump runs for default designated timeout period
- Sends an alert of node starting / stopping pump with runtime.



- Deployable as a node to report to a control server



- Battery Powered w/ Solar panel
- LoRa communications


### Added Features
- Dashboard / Track how much water is being used.
